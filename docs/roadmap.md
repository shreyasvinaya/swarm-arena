# Roadmap

The current release runs manual TOML and Python plans with scripted managers,
local tools, checks, judges, pruning policies, round snapshots, shared budgets,
and durable stop/resume. It includes an offline conformance kit and runnable
Rosenbrock and bring-your-own-script examples. Start with
[Getting started](getting-started.md) or [Planning modes](planning-modes.md).

The shared arena, human review, and curation are M2 work. Built-in model-provider
integrations, model-driven managers and judges, and LLM/together/autonomous
planning are M3 work. Ray and cluster execution remain future work. The
[offline kit](own-files.md#try-it-offline) is available without those integrations.
